# Rule: Naming Conventions

| Thing | Convention | Example |
|---|---|---|
| Folders | kebab-case | `docs/modules/audit-log/` |
| Ordinary docs | kebab-case.md | `business-rules.md` |
| Canonical anchors | SCREAMING_CASE.md | `STATUS.md`, `docs/shared/GLOSSARY.md` |
| Indexes | `_INDEX.md` (sorts first) | `docs/modules/_INDEX.md` |
| ADRs | `ADR-NNNN-short-title.md`, zero-padded, never renumbered | `ADR-0002-documentation-language.md` |
| Slash commands | verb-first kebab | `new-module.md` |
| Playbooks | kebab-case.md, named for the kind of work | `.claude/playbooks/bug-fix.md` |
| Module names | English kebab-case folder; Arabic name in the module's `overview.md` and `GLOSSARY.md` | `purchasing/` ↔ المشتريات |
