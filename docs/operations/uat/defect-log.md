**قواعد التصنيف — حسم المالك (2026-07-31، مع قرار GO): ثلاث فئات لا غير،
وهي نفسها فئات سجلّ التجربة [`pilot-findings.md`](../pilot-findings.md):**
- **Bug (عيب):** سلوك يخالف قاعدة عمل أو معيار قبول معتمدًا → يُصلح عبر
  البوّابات المعتادة (الإصلاح ليس قدرة جديدة — `BD-PRD-008`).
- **Usability (استخدامية):** النظام صحيح لكن المستخدم احتار أو أُبطئ →
  يقرّر المالك إن ومتى يُعالَج.
- **Enhancement (تحسين/قدرة):** شيء خارج النطاق المعتمد (خصم، طباعة،
  تقرير…) → **يُركن للمالك، ولا يُنفَّذ أثناء التجربة إلا إن حكم أنّه لازم
  لاستمرار التشغيل.**
