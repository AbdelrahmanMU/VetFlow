# Identity — Test Scenarios

> Status: **Approved** — owner ruling 2026-08-02.
> Authority: ADR-0022 §7.

### TS-IDN-001 — دخول ناجح
`01001127204` + كلمة المرور الصحيحة → رمز صالح، والانتقال إلى قائمة المنتجات.
→ AC-IDN-001

### TS-IDN-002 — محتوى الرمز
فكّ الرمز الناتج → يحمل المستخدم واسم العرض والمنشأة والفرع والدور، **ولا يحمل
كلمة المرور ولا مُجزّأها**. → AC-IDN-002

### TS-IDN-003 — كلمة مرور خاطئة
رقم صحيح + كلمة خاطئة → فشل بالرسالة الموحّدة. → AC-IDN-003

### TS-IDN-004 — رقم غير مسجَّل
رقم لا وجود له → **نفس الرسالة ونفس رمز الاستجابة** تمامًا كـ TS-IDN-003،
ويُقارَنان حرفيًّا. → AC-IDN-003

### TS-IDN-005 — مستخدم بلا عضوية
اعتماد صحيح وبلا عضوية → فشل بالرسالة نفسها. → AC-IDN-003، BR-IDN-007

### TS-IDN-006 — لا كلمة مرور صريحة
فحص صفّ المستخدم المخزَّن → لا يساوي النصّ الصريح. وفحص السجلّات → لا تحوي
كلمة المرور. → AC-IDN-004

### TS-IDN-007 — رفض الطلب بلا رمز
كلّ نقطة نهاية عمل بلا رمز → **مرفوضة**. نقطة الدخول → متاحة. → AC-IDN-005

### TS-IDN-008 — معرّف منشأة من العميل لا يُغيّر شيئًا
طلب موثَّق لمنشأة (أ) يحمل معرّف منشأة (ب) في الترويسة وفي المسار وفي الجسم →
**النتيجة بيانات (أ) في الحالات الثلاث**. → AC-IDN-006

### TS-IDN-009 — رمز مُشوَّه أو بمفتاح آخر
رمز مُعدَّل، ورمز موقَّع بمفتاح مختلف → **كلاهما مرفوض**، بلا تسريب سبب.
→ AC-IDN-007

### TS-IDN-010 — رمز منتهٍ
رمز انتهت صلاحيته → رفض، وإعادة إلى شاشة الدخول **برسالة**. → AC-IDN-008

### TS-IDN-011 — الخروج
بعد الخروج، طلب شاشة عمل → يُعاد إلى الدخول. → AC-IDN-009

### TS-IDN-012 — شاشة الدخول تتبع المعيار
إرسال نموذج فارغ → رسائل حقول وبؤرة على أوّل حقل غير صالح، والزرّ **غير
مُعطَّل**. فشل الخادم → لافتة تستقبل البؤرة وتُمسَح عند أوّل تعديل.
→ AC-IDN-010

### TS-IDN-013 — الإسناد إلى منفِّذ موثَّق
عملية مخزون بعد الدخول → الحركة منسوبة إلى المستخدم الموثَّق. → AC-IDN-011

### TS-IDN-014 — البذرة
بعد التهيئة: «Clinic Owner» موجود بدور **مالك** في المنشأة والفرع المُهيَّأين،
وكلمته مُجزَّأة. → AC-IDN-012

### TS-IDN-015 — تفرّد الهاتف عبر المنشآت
إنشاء مستخدم ثانٍ بنفس الرقم في منشأة أخرى → **يُرفَض**. → AC-IDN-013

### TS-IDN-016 — تحقّق المتصفّح
شاشة الدخول على ١٤٤٠×٩٠٠ و٣٩٠×٨٤٤: RTL · بلا تجاوز أفقيّ · بلا أخطاء وحدة
التحكّم · دخول حقيقيّ ينتهي بقائمة المنتجات · الخروج يعيد إلى الدخول.
→ AC-IDN-001/009/010
