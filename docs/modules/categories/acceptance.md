# Categories — Acceptance

> Status: Approved (2026-07-16) — Managed Data slice (Sprint 3), owner-ruled.

### AC-CTG-001 — قائمة التصنيفات (REQ-CTG-001)
- عند فتح شاشة التصنيفات تظهر التصنيفات القائمة مع حالتها، ويصفّي البحث بالاسم، ويعمل الفرز
  والترقيم، وتظهر الحالة الفارغة حين لا توجد تصنيفات.

### AC-CTG-002 — إنشاء تصنيف (REQ-CTG-002)
- إدخال اسم صالح غير مكرر يُنشئ تصنيفًا نشطًا يظهر فورًا في القائمة وفي اختيار محرر المنتج.
- الاسم الفارغ أو المكرر (بعد التطبيع) يُرفض برسالة تحقّق واضحة، دون إنشاء.

### AC-CTG-003 — إعادة تسمية تصنيف (REQ-CTG-003)
- تغيير الاسم إلى اسم صالح غير مكرر يُحفظ ويظهر في القائمة؛ المنتجات المرتبطة تعكس الاسم الجديد.
- محاولة التسمية باسم مكرر تُرفض.

### AC-CTG-004 — تنشيط/إلغاء تنشيط (REQ-CTG-004)
- إلغاء تنشيط تصنيف يُخفيه من اختيار المنتج الجديد ويُبقيه في القائمة بحالة «غير نشط».
- إعادة التنشيط تعيده لاختيار المنتج الجديد. لا يوجد إجراء حذف نهائي.

### AC-CTG-005 — تكامل محرر المنتج (REQ-CTG-005)
- محرر المنتج الجديد يعرض التصنيفات النشطة فقط.
- تحرير منتج بتصنيف صار غير نشط يعرض التصنيف الحالي مختارًا ويحفظه دون إجبار على تغييره.
- إذا غيّر المستخدم القيمة، فلا تظهر القيمة غير النشطة ضمن الخيارات المتاحة إلا بعد إعادة تنشيطها.
