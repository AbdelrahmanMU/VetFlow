# Categories — Overview

> Status: Approved (2026-07-16) — Managed Data slice (Sprint 3), owner-ruled.
> الاسم العربي للوحدة: **التصنيفات**.

## الغرض

تملك وحدة **التصنيفات** إدارة قائمة تصنيفات المنتجات التي يستهلكها الكتالوج: إنشاؤها
وتعديلها والبحث فيها وتنشيطها/إلغاء تنشيطها. تُزيل هذه الوحدة اعتماد النظام على بيانات
التصنيفات المزروعة يدويًا (seed) — يصبح بمقدور العيادة إدارة تصنيفاتها بنفسها.

## الحدود

- **تملك:** دورة حياة التصنيف (إنشاء · إعادة تسمية · تنشيط/إلغاء تنشيط · بحث · فرز · ترقيم).
- **لا تملك:** علاقة المنتج بالتصنيف — يملكها الكتالوج (BR-CAT-012: تصنيف واحد لكل منتج؛
  BR-CAT-013: قائمة مسطحة دون تسلسل هرمي). هذه الوحدة تُدير القائمة فقط.
- **يستهلكها:** محرر المنتج في الكتالوج (اختيار التصنيف — REQ-CTG-005).

## خارج النطاق (النسخة الأولى — MVP)

تسلسل هرمي للتصنيفات (BR-CAT-047 قدرة مستقبلية) · استيراد/تصدير · إجراءات جماعية ·
حذف نهائي · وصف أو حقول إضافية للتصنيف · أي إدارة متقدمة.
