# Categories — Requirements

> Status: Approved (2026-07-16) — Managed Data slice (Sprint 3), owner-ruled.

### REQ-CTG-001 — قائمة التصنيفات
- **المتطلب:** يعرض النظام قائمة التصنيفات مع البحث بالاسم، والفرز، والترقيم، والحالات
  الأربع للعرض (تحميل/فارغ/خطأ/بيانات) بنمط قائمة المنتجات المعتمد.
- **قواعد العمل:** BR-CTG-001، BR-CTG-004

### REQ-CTG-002 — إنشاء تصنيف
- **المتطلب:** يتيح النظام إنشاء تصنيف جديد بالاسم فقط؛ يُرفض الاسم الفارغ أو المكرر
  (بعد التطبيع) برسالة تحقّق لكل حقل.
- **قواعد العمل:** BR-CTG-001، BR-CTG-002، BR-CTG-003

### REQ-CTG-003 — تعديل (إعادة تسمية) تصنيف
- **المتطلب:** يتيح النظام إعادة تسمية تصنيف قائم، بنفس قيود الصحة والتفرّد، وبلا تدقيق في
  النسخة الأولى.
- **قواعد العمل:** BR-CTG-002، BR-CTG-003، BR-CTG-007

### REQ-CTG-004 — تنشيط/إلغاء تنشيط تصنيف
- **المتطلب:** يتيح النظام تنشيط تصنيف أو إلغاء تنشيطه؛ لا حذف نهائي في النسخة الأولى.
- **قواعد العمل:** BR-CTG-004، BR-CTG-005، BR-CTG-006

### REQ-CTG-005 — تكامل محرر المنتج
- **المتطلب:** يعرض اختيار التصنيف في محرر المنتج **التصنيفات النشطة فقط** عند إنشاء منتج
  جديد. وعند تحرير منتج تصنيفه صار غير نشط، تُحفظ قيمته الحالية وتُعرض دون إجبار على تغييرها.
- **قواعد العمل:** BR-CTG-005، BR-CTG-008
