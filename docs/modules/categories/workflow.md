# Categories — Workflow

> Status: Approved (2026-07-16) — Managed Data slice (Sprint 3), owner-ruled.
> هيكلي: يصف المسارات فقط.

- **إنشاء:** الطبيب/المساعد يفتح «التصنيفات» ← «تصنيف جديد» ← إدخال الاسم ← حفظ ← يظهر في
  القائمة نشطًا ومتاحًا فورًا في اختيار محرر المنتج.
- **إعادة تسمية:** فتح تصنيف ← تعديل الاسم ← حفظ (بلا تدقيق — النسخة الأولى).
- **إلغاء التنشيط:** إجراء الصف ← يصبح «غير نشط» ← يختفي من اختيار المنتج الجديد؛ المنتجات
  القائمة لا تتأثر (DEC-CTG-002، الخيار ب).
- **إعادة التنشيط:** إجراء الصف ← يعود للاختيار.
- **مسار استثناء:** اسم فارغ/مكرر ← رسالة تحقّق، لا حفظ.
