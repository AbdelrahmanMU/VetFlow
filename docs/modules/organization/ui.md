# Organization — UI

> Status: **Approved** — owner ruling 2026-08-02.
> Authority: ADR-0022.

## لا واجهة لهذه الوحدة

**بحسم المالك (2026-08-02): لا واجهة فروع، ولا تبديل فروع، ولا إدارة منشآت،
ولا إدارة مستخدمين، ولا إدارة صلاحيات.** الوحدة أساس تنظيميّ لا قدرة يستعملها
المستخدم.

هذا الملفّ موجود لأنّ **مجموعة ملفّات الوحدة قياسيّة** (قاعدة التوثيق)، ولأنّ
غيابه يجعل الوحدة تبدو ناقصة التوثيق بدل أن تكون **مقصودة بلا واجهة**.

## الأثر الوحيد الظاهر للمستخدم

**لا شيء.** الشاشات القائمة كما هي حرفيًّا: القوائم والفلاتر والفرز والترقيم
والنصوص العربية **لا يتغيّر منها شيء**، لأنّ المنشأة والفرع مشتقّان لا
مختارَين، ولأنّ البذرة منشأة واحدة وفرع واحد.

**لا نصّ عربيّ جديد** تُدخِله هذه الوحدة.

## ما سيلزمه توثيق واجهة مستقبلًا (ليس الآن)

عند تفعيل الفروع فعليًّا: مؤشّر الفرع الحالي · اختيار الفرع · شاشة إدارة
الفروع. **كلّها خارج النطاق، ولا تُصمَّم هنا ولا يُخترع لها نصّ.**
