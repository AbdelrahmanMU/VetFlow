# Organization — Workflow

> Status: **Approved** — owner ruling 2026-08-02.
> Authority: ADR-0022.

## اشتقاق السياق التنظيميّ (المسار الوحيد)

```
المستخدم يسجّل الدخول            ← وحدة Identity
        ↓
تُقرأ عضويته: المنشأة + الدور
        ↓
يُحدَّد فرعه
        ↓
تُحمَل المنشأة والفرع والمستخدم في مطالبات الرمز (JWT)
        ↓
كلّ طلب لاحق يحمل الرمز
        ↓
يُبنى «سياق المنشأة» من المطالبات وحدها
        ↓
كلّ قراءة تُرشَّح بالمنشأة تلقائيًّا
كلّ كتابة تُوسَم بالمنشأة والفرع تلقائيًّا
```

**لا يوجد مسار بديل.** لا إعداد، ولا ترويسة، ولا معامل مسار، ولا ثابت في
الكود — ADR-0022 §3 و§11.2.

## إنشاء عميل جديد (خارج الواجهة، مسار تشغيليّ)

```
إنشاء منشأة  →  إنشاء فرع  →  إنشاء مستخدم مالك بعضوية
```

ثلاث خطوات، بلا هجرة بيانات وبلا تغيير في المجال. **لا واجهة لهذا المسار في
هذه المرحلة** — بحسم المالك.

## ما لا يحدث

- **لا اختيار منشأة** عند الدخول (مستخدم البذرة له عضوية واحدة).
- **لا اختيار فرع** عند العمل (فرع واحد).
- **لا تبديل فرع** أثناء الجلسة.
