# Purchasing — Workflow

> Status: Approved (2026-07-16) — Slice 1 (Purchase List), Sprint 4; Approved (2026-07-17) — Slice 4 (WF-PUR-LINES).

## WF-PUR-LIST — استعراض قائمة المشتريات
1. يفتح المستخدم «المشتريات» من التنقّل.
2. يعرض النظام قائمة فواتير الشراء (أحدث فاتورة أولًا افتراضيًا) بالحالات الأربع للعرض.
3. يبحث/يفلتر/يفرز/يتنقّل بين الصفحات (BR-PUR-004).

## WF-PUR-LINES — إضافة/حذف بنود فاتورة مسودة (Slice 4)
1. يفتح المستخدم **تفاصيل** فاتورة **مسودة** (REQ-PUR-002).
2. في قسم «بنود الفاتورة» يضغط **«إضافة بند»** → يفتح حوار الإضافة.
3. يختار **منتجًا** نشِطًا، ثم **وحدة شراء** من وحدات شراء المنتج، ويُدخِل **الكمية** و**سعر الوحدة**.
4. يعرض الحوار **إجمالي البند** (الكمية × سعر الوحدة) للقراءة؛ عند الحفظ:
   - فشل التحقق (كمية ≤ 0 / سعر < 0 / منتج أو وحدة مفقودان) → خطأ **حقلًا بحقل**، لا إضافة (AC-PUR-009).
   - نجاح → يُضاف البند، ويُعاد حساب **إجمالي الفاتورة** فورًا داخل التجميعة (BR-PUR-006)، ويظهر البند.
5. **حذف بند:** إجراء صف يزيل البند فورًا ويعيد حساب الإجمالي (AC-PUR-010)؛ قد تصبح الفاتورة بلا بنود (إجمالي صفر).
6. التغيير مسموح **للمسودة فقط** (AC-PUR-012)؛ لا استلام ولا أثر على المخزون في هذه الشريحة.

> انتقالات الحالة (مسودة → مستلمة، الإلغاء) والاستلام وأثر المخزون: تُوثَّق في شرائحها.
