# Purchasing — Test Scenarios

> Status: Approved (2026-07-16) — Slice 1 (Purchase List); Approved (2026-07-17) — Slice 2 (Purchase Details); Approved (2026-07-17) — Slice 3 (Create Purchase). Sprint 4.

### TS-PUR-001 — عرض القائمة مع بيانات
معطى فواتير شراء موجودة، عند فتح الشاشة تُعرض بالأعمدة الستة (رقم النظام، المورد، تاريخ الفاتورة،
الحالة، الإجمالي، تاريخ الإنشاء) وأحدث فاتورة أولًا. (REQ-PUR-001، BR-PUR-004)

### TS-PUR-002 — الحالة الفارغة
معطى لا فواتير، تُعرض حالة «فارغ». (REQ-PUR-001)

### TS-PUR-003 — البحث باسم المورد (تطبيع عربي)
البحث بجزء من اسم المورد يُرجِع الفواتير المطابقة بعد التطبيع العربي. (BR-PUR-004)

### TS-PUR-004 — فلتر الحالة
تحديد «مسودة» يقصر النتائج على المسودات. (BR-PUR-004)

### TS-PUR-005 — الفرز والترقيم المستقر
الفرز بالتاريخ/الإجمالي مع مُكسِّر تعادل ثابت (المعرّف) وترقيم مستقر عبر الصفحات. (BR-PUR-004)

### TS-PUR-006 — شارة الحالة العربية
كل صف يعرض شارة الحالة الصحيحة: مسودة / مستلمة / ملغاة. (AC-PUR-002)

### TS-PUR-007 — تنسيق رقم النظام
يُعرض رقم النظام بالصيغة `PUR-000001`. (AC-PUR-003)

## Slice 2 — Purchase Details

### TS-PUR-008 — عرض التفاصيل مع بيانات
معطى فاتورة موجودة، عند فتح تفاصيلها تُعرض ترويستها كاملةً للقراءة فقط (شارة الحالة، رقم النظام،
اسم المورد، مرجع فاتورة المورد، تاريخ الفاتورة، الإجمالي، الملاحظات، تاريخ الإنشاء). (REQ-PUR-002، AC-PUR-004)

### TS-PUR-009 — فاتورة غير موجودة
معطى معرّف فاتورة لا يوجد، تُعرض حالة «غير موجود». (REQ-PUR-002، AC-PUR-005)

### TS-PUR-010 — الحقول الاختيارية
حين يغيب مرجع فاتورة المورد أو الملاحظات، تتصرّف الشاشة بلا خطأ (تُخفى القيمة أو يظهر بديل)؛ وحين
توجد تُعرض كما هي. (REQ-PUR-002، BR-PUR-001)

### TS-PUR-011 — شارة الحالة ورقم النظام في التفاصيل
تُعرض شارة الحالة الصحيحة (مسودة/مستلمة/ملغاة) ورقم النظام بالصيغة `PUR-000001` في شاشة التفاصيل.
(AC-PUR-002، AC-PUR-003)

## Slice 3 — Create Purchase

### TS-PUR-012 — إنشاء ناجح
معطى اسم مورد وتاريخ فاتورة صحيحين، عند الحفظ تُنشأ فاتورة **مسودة** برقم `PUR-` مُولَّد وإجمالي صفر،
وينتقل المستخدم إلى شاشة تفاصيلها. (REQ-PUR-003، AC-PUR-006)

### TS-PUR-013 — الحقول المطلوبة
حذف اسم المورد أو تاريخ الفاتورة يمنع الحفظ ويُظهر خطأً **حقلًا بحقل**، دون إنشاء أيّ فاتورة. (REQ-PUR-003، AC-PUR-007)

### TS-PUR-014 — الحقول الاختيارية
يُسمح بالحفظ بدون مرجع المورد وبدون ملاحظات؛ وحين تُدخَل تُحفظ كما هي (تُقصّ المسافات، والفارغ يُعامَل كغياب). (REQ-PUR-003، BR-PUR-001)

### TS-PUR-015 — الرقم والحالة يُولَّدان آليًا
رقم النظام يُولَّد بالصيغة `PUR-000001` عند الحفظ (تسلسل تصاعدي فريد)، والحالة الابتدائية **مسودة** دائمًا
— لا يختارهما المستخدم. (BR-PUR-002، BR-PUR-003)
