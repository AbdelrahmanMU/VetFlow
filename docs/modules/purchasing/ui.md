# Purchasing — UI

> Status: Approved (2026-07-16) — Slice 1 (Purchase List), Sprint 4.
> يلتزم بلغة التصميم المعتمدة و`docs/ui/` — RTL، خصائص CSS منطقية، مكوّنات VetFlow UI Kit فقط.

## شاشة قائمة المشتريات

- **العنوان:** «المشتريات».
- **الأعمدة (مجمّدة):** رقم النظام · المورد · تاريخ الفاتورة · الحالة (شارة) · الإجمالي (EGP) ·
  تاريخ الإنشاء. لا أعمدة إضافية (BR-PUR-004).
- **مرجع فاتورة المورد (عرض فقط، ليس عمودًا):** حين يوجد، يُعرض **سطرًا ثانويًا صغيرًا أسفل اسم المورد**
  داخل خانة «المورد» (بادئة «مرجع المورد:») — على نمط السطر الثانوي في قائمة المنتجات (الحجم/التركيز).
  ليس عمودًا سابعًا؛ حقلٌ معتمد يدخل البحث (BR-PUR-001، BR-PUR-004). يبقى العدّ ستة أعمدة.
- **البحث:** حقل بحث واحد — «ابحث برقم الفاتورة أو اسم المورد أو مرجع المورد…» (رقم النظام /
  اسم المورد / مرجع فاتورة المورد **فقط** — لا يشمل الملاحظات، BR-PUR-004).
- **الفلاتر:** الحالة (مسودة/مستلمة/ملغاة)، ومدى تاريخ الفاتورة (من/إلى) — لا غير.
- **الفرز:** رقم النظام · تاريخ الفاتورة · المورد · الحالة · الإجمالي.
- **شارات الحالة (دلالة فقط — الألوان تخصّ لغة التصميم، لا تُعرَّف هنا):**
  - مسودة → **محايد (Neutral)**
  - مستلمة → **نجاح (Success)**
  - ملغاة → **خطر (Danger)**
- **الحالات الأربع للعرض:**
  - **تحميل** → هيكل (`VfSkeleton`).
  - **فارغ** → النص: «لا توجد فواتير شراء حتى الآن»، مع زرّ رئيسي: «إنشاء فاتورة شراء».
    **الزرّ غير مُفعَّل عمدًا حتى شريحة الإنشاء (Slice 3)** — لا يُنفَّذ الآن.
  - **خطأ** → رسالة خطأ مع إعادة المحاولة.
  - **بيانات** → الجدول (سطح المكتب) / البطاقات (الجوال).
- **الاستجابة:** جدول (`VfTable`) على سطح المكتب، وبطاقات على الجوال — نمط قائمة المنتجات المعتمد.

> نصوص عربية أخرى (الإنشاء/الاستلام): تُضاف عند شرائحها.
